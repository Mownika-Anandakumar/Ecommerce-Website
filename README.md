This project is a full-featured **E-commerce web application** designed for selling beauty and cosmetic products online. Developed in **May 2024** as part of a web development academic project, this platform demonstrates the integration of frontend and backend technologies to deliver a complete shopping experience to users.

## 🌐 Project Overview

The website allows users to browse products, view detailed descriptions, and make purchases by adding items to their cart. It also features user authentication, where customers can register, log in, and manage their profiles. Each product includes images, descriptions, prices, and discount options to enhance the shopping experience.

The application was developed using a combination of technologies:
- **Frontend**: HTML, CSS, JavaScript for responsive design and user interactions.
- **Backend**: Java and JSP (Java Server Pages) for server-side logic and dynamic content rendering.
- **Database**: MySQL for storing user accounts, product data, order history, and cart information.

## 🛠 Key Features

- **User Authentication**: Secure login and registration with input validation.
- **Product Catalog**: Display of beauty products with image previews and price filtering.
- **Shopping Cart**: Add, remove, and update items in the cart before checkout.
- **Discount System**: Apply promotions or deals on eligible items.
- **Database Integration**: MySQL used for reliable product and customer data storage.
- **Responsive Design**: Works across desktop and mobile browsers.
